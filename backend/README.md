# Risk Management Dashboard

A full‑stack web application for managing enterprise risks, audit logs, and user authentication.  
Built with **React (frontend)**, **Node.js + Express (backend)**, and **MongoDB Atlas (database)**.

---

## 🚀 Features
- **Authentication**: Login with JWT, logout clears token.
- **Protected Routes**: Risks, New Risk, Audit Logs, and Dashboard only accessible when logged in.
- **Risk Management**:
  - View risks in a table.
  - Add new risks via form.
- **Audit Logs**: Track system activity and user actions.
- **Dashboard**: Interactive view of risks.
- **Responsive UI**: Styled homepage cards, navbar, tables, and forms.

---

## 🛠️ Tech Stack
- **Frontend**: React, React Router, CSS (Netlify deploy ready)
- **Backend**: Node.js, Express, JWT, MongoDB Atlas (Render deploy ready)
- **Database**: MongoDB Atlas
